Comenzando

1. Primeros Pasos con VXR Core

VXR Core es un framework de alto nivel en TypeScript sobre Three.js y WebXR Device API. Para comenzar, agrega la biblioteca y sus tipos a tu proyecto de Node/Vite:

npm install github:Vickman123/Framework-XVR three @types/three

Instancia la fachada maestra XRApp para configurar canvas, cámara, luces y bucle de animación automáticamente:

import { XRApp } from 'vxr'; const app = new XRApp({ container: '#app', autoVRButton: true, enableShadows: true, pixelRatioCap: 1.5 }); await app.loadModel('./models/artefacto.glb', { autoGround: true }); app.start();

Diseño y Filosofía

2. Arquitectura del Sistema

VXR Core sigue el patrón Fachada Abierta (Open Facade): resuelve tareas repetitivas pero te permite acceder a app.scene, app.camera y app.renderer en cualquier momento sin restricciones.

Capa Módulo Propósito
Fachada XRApp Control de ciclo de vida y orquestación unificada.
Escena XRScene Presets de iluminación y fondo equilibrados.
Render XRRenderer WebGL2, pixelRatioCap adaptativo y WebXR loop.
Assets XRAssetManager GLTF/GLB, DRACO, auto-grounding y dispose GPU.
Inmersión XRSession Detección WebXR, mandos VR y emulación Desktop.

3. Escenas y Renderizado

El módulo XRScene ofrece presets de iluminación fotométricos listos para usar:

app.sceneManager.applyLightingPreset('studio'); // 'studio' | 'outdoor' | 'sunset' | 'cyber'

XRRenderer restringe el pixelRatio a un máximo de 1.5x (pixelRatioCap: 1.5) para prevenir calentamiento térmico en Meta Quest y móviles.

4. Recursos 3D y Auto-Grounding

Carga modelos 3D con centrado automático y alineación de suelo mediante Box3:

const model = await app.loadModel('./models/artefacto.glb', { autoCenter: true, autoGround: true, castShadow: true });

Para liberar memoria al cambiar de escena:

app.assetManager.disposeObject(model);

5. Interacción Unificada (XRInput)

XRInput unifica la entrada de ratón, teclado (WASD) y mandos WebXR con botones y gatillos:

import { XRInput } from 'vxr'; const input = new XRInput({ canvas: app.renderer.domElement }); input.on('select', (event) => { console.log('Intersección con objeto:', event.intersection?.object); });

7. Escenarios y Salas Modulares

Construcción procedimental de salas conectadas por pasillos continuos con colisiones automáticas:

import { XRRoom, XRScenario } from 'vxr'; const room = new XRRoom({ dimensions: { width: 12, height: 4, depth: 12 }, materials: { floor: 'marble', walls: 'white' }, doors: [{ wall: 'north', width: 2.2, height: 3.0 }] }); const scenario = new XRScenario(); scenario.addRoom(room); app.scene.add(scenario);

10. Solución de Problemas

Incidencia Causa Solución
WebXR no arranca Red local sin HTTPS. Usa npx vxr serve --https.
Pérdida de contexto WebGL Memoria GPU saturada. Ejecuta app.dispose() al cambiar de vista.
Sin audio en móvil Autoplay policy de Safari/Chrome. Llama a audio.unlock() en el primer tap.
