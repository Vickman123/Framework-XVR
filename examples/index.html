DE LA CURIOSIDAD A LA PRODUCCIÓN

El Viaje del Creador: De la Idea a la Realidad en 5 Pasos

VXR acorta radicalmente la distancia entre imaginar una experiencia inmersiva y verla cobrar vida en tres dimensiones. Cinco etapas diseñadas para que cualquier persona pueda aprender, construir, probar, publicar y compartir sin fricciones.

PASO 01 • APRENDE
💡

1. Aprende

Learning Mode sin jerga opaca

Aprende haciendo desde cero. Documentación pedagógica clase por clase, desgloses conceptuales (cámaras, mallas, luces, WebXR) y código pensado para desarrolladores web que dan el salto al 3D.

  • Explicaciones clase por clase
  • Conceptos 3D sin complicaciones
  • Ejemplos interactivos listos
Explorar Learning Mode →
PASO 02 • CREA
🛠️

2. Crea

Plantillas modulares y salas 3D

Construye salas procedimentales con XRRoom, suelta modelos 3D con auto-grounding automático (Y=0), añade pedestales de exposición y sonido procedural nativo con Web Audio sin archivos pesados.

  • XRRoom con paredes y puertas
  • Auto-grounding de modelos .glb
  • Audio procedural Web Audio (0 MB)
Ver Código y Plantillas →
PASO 03 • PRUEBA
🥽

3. Prueba

Instantáneo en el navegador

Sin compilar APKs ni esperar horas. Abre tu proyecto en Chrome, Edge o en el navegador de Meta Quest. El simulador desktop te permite probar interacciones con mouse y teclado antes de ponerte las gafas.

  • Simulador desktop automático
  • Modo VR/AR nativo en Quest
  • Loop fluido a 90 FPS estables
Probar Demos en Vivo →
PASO 04 • PUBLICA
🚀

4. Publica

CLI & Meta Quest Optimizer

Con un simple comando "vxr build --target quest", empaqueta tu proyecto en una Progressive Web App (PWA) optimizada con compresión de assets, HTTPS y auditoría de salud automática con "vxr doctor".

  • Auditoría técnica con vxr doctor
  • PWA WebXR lista para instalar
  • Optimizado para Meta Quest Browser
Ver Comandos CLI →
PASO 05 • COMPARTE
🌐

5. Comparte

Una URL, acceso para todos

Tu experiencia vive en la web abierta. Alójala gratis en GitHub Pages, Vercel o tu propio servidor. Envía un enlace o imprime un código QR para que cualquier persona en el mundo entre con un clic.

  • Alojamiento web estático gratuito
  • Acceso universal por enlace o QR
  • Fomenta la comunidad y el aprendizaje

import { XRApp } from 'vxr';

const app = new XRApp({
  container: "#app",
  autoVRButton: true,
  enableShadows: true,
  enableGrid: true,
  pixelRatioCap: 1.5
});

await app.loadModel('./models/edificio.glb', {
  autoGround: true,
  autoCenter: true
});

app.start();

IMPACTO SOCIAL, CIENTÍFICO Y EDUCATIVO

Impulsando el Ecosistema XR en México y LatAm

VXR nace con una convicción clara: la Realidad Virtual y Aumentada no debe ser un privilegio de estudios con licencias costosas ni hardware privativo. Democratizamos las herramientas inmersivas para el aula, el laboratorio científico, el estudio creativo y los desarrolladores independientes.

🎓

Educación Pública & Universidades

Permite a docentes, escuelas y facultades crear laboratorios virtuales, prácticas técnicas seguras y museos históricos interactivos que se ejecutan directamente en cualquier navegador o visor sin costos de suscripción.

#AulasInmersivas #CienciaAbierta #EducaciónPública
💻

Desarrolladores Web & Estudiantes

Aprovecha tus conocimientos de JavaScript, TypeScript y la web abierta para entrar al mundo 3D y WebXR sin tener que aprender motores cerrados ni lenguajes ajenos. Todo con una arquitectura Open Facade transparente.

#WebDevToXR #OpenFacade #TypeScript
🎨

Artistas, Arquitectos & Creadores

Transforma modelos 3D (.glb) en exposiciones interactivas con fichas técnicas automáticas, sonido espacial y navegación inmersiva en escala 1:1, listas para ser visitadas por el público en minutos.

#ArteDigital #Patrimonio #BIM
